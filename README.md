# VANTA

**VANTA** is an ultra-realistic open-world Android game project, starting from a clean repository.

## Direction
- Third-person open-world exploration
- Realistic character and vehicle physics
- PBR materials, dynamic lighting and weather-ready systems
- Large-world streaming architecture
- Touch-first Android controls
- Scalable Low / Medium / High / Ultra graphics
- Mobile-first performance budgets

## Production engine
Unreal Engine 5 is the intended production engine for the full 3D game. This repository starts with the game design, architecture and prototype systems that can be migrated into the UE5 project.

## Current milestone
Vertical-slice foundation: player + camera, vehicle physics model, world streaming plan, mobile controls, scalability and save-system interfaces.
