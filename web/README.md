# VANTA Browser Prototype

A lightweight playable prototype for desktop and mobile browsers. It demonstrates third-person movement, a follow camera, vehicle mode, a large terrain plane, road, simple world props, shadows and mobile touch controls.

## Run
Open `web/index.html` through a static web server. The browser imports Three.js from jsDelivr, so internet access is required.

This is a prototype, not the final ultra-realistic Android game. The production game is planned for Unreal Engine 5.
